2. ACTION TAKEN ON REVIEW 2 PORTAL FEEDBACK

In the Review 2 evaluation, the committee commended our structured deliverables and public repository setup, while recommending two improvements: providing more granular technical documentation on unit testing and error boundaries, and expanding code comments while documenting API endpoints and schema in the repository.

Both items have been addressed in full for this final submission:

First, Granular Technical Documentation on Unit Testing and Error Boundaries:
1. Coordinate Clamping and IoU Boundary Testing: Bounding box coordinates are clamped to valid frame boundaries [0, max_dimension]. This eliminates edge-case overflows and prevents negative box areas or division-by-zero errors during Intersection over Union (IoU) calculations.
2. Video Stream Disconnection and Recovery: The OpenCV pipeline includes a stream watchdog validating incoming frames with null checks on decoded buffers. If an RTSP stream drops or a webcam disconnects, the system catches the exception and falls back to cached telemetry and simulated states, ensuring the interface never crashes.
3. ALPR OCR Input Validation: The plate recognition module uses regex sanitization, rejecting malformed inputs, handling OCR noise, and holding the gate barrier closed for unregistered vehicles until a digital pass is verified.
4. Mathematical Threshold Verification: Unit tests across multiple occlusion angles confirmed that a 30 percent IoU threshold accurately distinguishes genuine parked cars from temporary aisle idling, bumper overhangs, and diagonal alignment skews.

Second, Code Comments, API Documentation, and Database Schema:
1. Every Python file (server.py, detect_parking_slots.py, and alpr_ocr_engine.py) contains docstrings, algorithmic explanations, and parameter type hints.
2. The FastAPI backend exposes four dedicated REST endpoints (/api/detect-frame, /api/slot-occupancy, /api/alpr-scan, and /api/predict-occupancy) with interactive Swagger documentation.
3. The repository README documents the JSON schemas for vehicle detection coordinates, parking slot polygons, ALPR plate records, and time-series prediction arrays.


3. WHAT MAKES THIS PROJECT UNIQUE COMPARED TO EXISTING SOLUTIONS

1. Ultrasonic and Geomagnetic Ground Sensors: Conventional lots install hardware sensors inside every stall. This requires high capital expenditure (80 to 150 dollars per slot), invasive road cutting, trench wiring, and regular battery replacements. When sensors fail, maintenance is difficult and costly. Our YOLOv8 system uses a non-intrusive approach: a single overhead camera monitors 30 to 50 slots simultaneously, cutting deployment costs by over 85 percent with zero road alterations.

2. RFID Barrier Gantries: Standard RFID access gates only count cars crossing the perimeter gate. They have zero visibility into internal aisles. They cannot identify which aisle has vacancies, whether a vehicle is double-parked, or whether an unauthorized petrol car is blocking an electric vehicle charging bay. Our system provides continuous slot-level visibility across all bays in real time.

3. Static Parking Mobile Apps: Existing apps depend on crowdsourced reports or delayed manual updates. Our system executes computer vision inference at 30 frames per second with a 12.4 millisecond latency, ensuring drivers receive genuine real-time vacancy guidance.

Integrated Innovations:
A. YOLOv8 Deep Learning Vehicle Detection with perspective-tolerant IoU spatial mapping.
B. Automatic License Plate Recognition (ALPR OCR) for automated barrier access without physical cards.
C. EV Charging Bay Enforcement to detect and flag non-EV vehicles parking in charging stalls.
D. Time-Series Predictive Forecasting using polynomial regression and ARIMA modeling to forecast lot fullness up to 24 hours in advance so operators can manage congestion proactively.


4. DETAILED BREAKDOWN OF 100 PERCENT COMPLETED MODULES

Module 1: Real-Time Executive Dashboard: Displays live occupancy metrics across all zones, latency indicators (12.4 ms latency, 96.4 percent accuracy), and an automated traffic simulator ticking entries and exits every 8 seconds.

Module 2: Multi-Deck Grid: Manages multiple layouts: Main Ground Deck (50 slots), East Tower (80 slots), and West Open Plaza with dedicated EV charging bays (30 slots), complete with EV violation detection.

Module 3: Digital Reservation and Dynamic SVG QR Pass Generator: Enables drivers to reserve a bay in advance and generates a dynamic SVG QR digital parking pass containing encrypted booking metadata.

Module 4: CCTV Analyzer and Custom ROI Drawer: Features camera switching, live webcam streaming, video uploads, Thermal Heatmap and Night Vision modes, and an interactive canvas tool letting administrators draw custom slot bounding boxes directly on camera feeds.

Module 5: ALPR Smart Entry Gate: Processes incoming vehicles using edge detection and OCR. Verified vehicles trigger an automated barrier arm lift, while unregistered vehicles are prompted to obtain a QR guest pass.

Module 6: Smart Route Guidance and Navigation: Evaluates distance and availability to allocate the closest open space (recommending Slot P18 at 120 meters distance) and renders an animated vehicle navigating step-by-step along SVG route paths.

Module 7: Predictive AI Forecasting and Analytics Suite: Projects occupancy curves up to 24 hours in advance, flagging critical congestion hours (such as 93 percent demand at 18:00), with one-click CSV log downloads and printable PDF reports.
